# راهنمای مدیر

همه بخش‌ها در «مدیریت سامانه» (منوی کناری) هستند؛ هر کارمند فقط بخش‌هایی را می‌بیند که دسترسی دارد.

| بخش | کاربرد |
| --- | --- |
| داشبورد | کاربران فعال روزانه/هفتگی/ماهانه، آمار امروز، نمودارهای ۳۰ روزه |
| کاربران | جستجو، وضعیت حساب، نشان تأیید، اصلاح Stars، نقش‌ها و کشورهای تحت پوشش، ورود به جای کاربر |
| محتوا و بررسی | مخفی، رد یا انتشار مجدد صفحه‌ها و پیشنهادها |
| مالی | درآمد، پرداخت‌ها، Stars فروخته/مصرف/هدیه |
| گزارش‌ها | ۱۵ شاخص در بازه روزانه تا سالانه، کشورها، دسته‌ها، فعال‌ترین کاربران |
| خروجی Excel | XLSX/CSV کاربران، پرداخت‌ها، تراکنش‌ها، پیشنهادها |
| نقش‌ها | ساخت نقش و تعیین دسترسی با محدوده خودش/تیم/دپارتمان/همه |
| رویدادهای امنیتی | ثبت همه کارهای حساس |
| نسخه‌های پشتیبان | ساخت، دانلود و حذف |
| تنظیمات | قیمت‌ها، بسته‌های Star، هزینه انتشار، حالت هزینه مشاهده صفحه، سقف ارسال گروهی، حجم تصویر، آمار صفحه اصلی، پشتیبان خودکار |
| بروزرسانی | آپلود ZIP نسخه جدید |

کارهای حساس (تعلیق/مسدود، تغییر Stars، نقش‌ها، ورود به جای کاربر، پشتیبان، بروزرسانی) رمز عبور مدیر را دوباره می‌خواهند.

نامه‌های رسمی آراد برندینگ و «تازه‌های سامانه» در بخش «ارتباطات» قرار دارند و فقط دارندگان مجوز مربوط می‌توانند بنویسند.
