# API داخلی آراد کانتکت

نشانی پایه: `https://aradbranding.app/api/integrations/arad-contact`

## احراز هویت

در همه درخواست‌ها این سربرگ را بفرستید:

```
Authorization: Bearer ab_xxxxxxxx_…
```

- کلید را مدیر کل در **مدیریت → اتصال API → کلید جدید** می‌سازد. کلید فقط یک بار نمایش داده می‌شود.
- دسترسی‌های لازم کلید:
  - `users.read` برای استعلام
  - `users.create` برای ساخت حساب
  - `wallet.charge` برای نرخ و شارژ
- می‌توان کلید را به IPهای سرور آراد کانتکت محدود کرد.
- درخواست بدون کلید یا با کلید نادرست پاسخ `401` با `{"error":"unauthorized"}` می‌گیرد. اگر کلید دسترسی لازم را نداشته باشد، پاسخ `403` با `{"error":"forbidden"}` است.

## قالب داده

- بدنه درخواست JSON است و `Content-Type: application/json` لازم است.
- پاسخ‌ها JSON ساده‌اند و بسته‌بندی اضافه ندارند.
- خطاها این شکل را دارند: `{"error": "<کد>", "message": "…", "errors": {…}}`.
- سقف ۳۰۰ درخواست در دقیقه است.
- همه درخواست‌ها در «آخرین درخواست‌ها» صفحه اتصال API ثبت می‌شوند.

## جلوگیری از تکرار (`external_id`)

اولین نتیجه هر `external_id` ذخیره می‌شود. هر درخواست دوباره با همان `external_id` همان نتیجه قبلی را با `"replayed": true` برمی‌گرداند و کاری دوباره انجام نمی‌شود. این شامل تکرار به‌علت قطعی اینترنت و حتی چند درخواست هم‌زمان می‌شود.

- **شارژ:** فقط یک بار انجام می‌شود. این را در آزمایش با ۶ درخواست هم‌زمان بررسی کرده‌ایم.
- **ساخت حساب:** حساب تکراری ساخته نمی‌شود. رمز موقت تا ۷ روز در پاسخ تکراری هم برگردانده می‌شود؛ رمز به‌صورت رمزنگاری‌شده نگه داشته می‌شود. پس از ۷ روز به‌جای رمز `null` برمی‌گردد.
- درخواستی که با خطا تمام شود (مثلاً کاربر پیدا نشد) ذخیره نمی‌شود و می‌توان آن را دوباره فرستاد.

## ۱. استعلام حساب

`POST /users/lookup`

```json
{"phones": ["09121234567", "۰۹۳۵۱۱۱۲۲۳۳", "+98 912 765 4321"]}
```

- حداکثر ۲۰ شماره در هر درخواست.
- شماره‌ها پیش از جست‌وجو یکسان‌سازی می‌شوند: ارقام فارسی و عربی، `0912…`، `912…`، `98912…`، `+98…` و `0098…` همه پذیرفته می‌شوند.
- اولین شماره‌ای که حساب دارد، به ترتیب فهرست، برگردانده می‌شود.

```json
{"found": true, "user_id": 123, "phone": "09121234567"}
```

```json
{"found": false}
```

## ۲. ساخت حساب

`POST /users`

```json
{"full_name": "رضا محمدی", "phone": "09121234567", "external_id": "arad-contact-customer-845"}
```

پاسخ `201`:

```json
{"user_id": 202, "username": "09121234567", "password": "8mGgXmAmGCXT", "login_url": "https://aradbranding.app/login", "created": true}
```

- نام کاربری همان شماره موبایل است.
- رمز موقت ۱۲ نویسه است. به مشتری بگویید پس از ورود آن را عوض کند.
- اگر این شماره از قبل حساب داشته باشد، حساب جدید ساخته نمی‌شود. همان حساب با `"created": false` و `"password": null` برگردانده می‌شود و رمز قبلی کاربر دست نمی‌خورد.
- اگر همان `external_id` دوباره بیاید، پاسخ اول با `"replayed": true` برمی‌گردد.

## ۳. نرخ Stars

`GET /stars/rate`

```json
{"toman_per_star": 1000}
```

این نرخ همان نرخ «تومان به ازای هر Star» در **مدیریت → تنظیمات** است.

## ۴. شارژ کیف پول

`POST /stars/credit`

```json
{"user_id": 123, "amount_toman": 5000000, "external_id": "arad-contact-item-9921", "note": "سفارش ۹۹۲۱"}
```

```json
{"stars": 5000, "toman_per_star": 1000, "balance": 7300, "transaction_id": "68", "remainder_toman": 0}
```

- تعداد Stars برابر است با `floor(amount_toman / toman_per_star)` با نرخ لحظه درخواست.
- `remainder_toman` آن بخش از مبلغ است که به یک Star کامل نرسیده است.
- شارژ در گردش حساب کیف پول کاربر با عنوان «شارژ کیف پول (ثبت سفارش در آراد کانتکت)» ثبت می‌شود. توضیح آن شامل مبلغ، `note` و `external_id` است.
- کاربر اعلان می‌گیرد و رویداد در لاگ امنیتی ثبت می‌شود.

**خطاها:**

| HTTP | `error` | معنی |
| --- | --- | --- |
| `404` | `user_not_found` | حسابی با این `user_id` نیست. |
| `422` | `amount_too_small` | مبلغ از قیمت یک Star کمتر است. |
| `422` | `validation` | ورودی نامعتبر است. |
| `409` | `busy` | همان `external_id` در همین لحظه در حال پردازش است؛ چند ثانیه بعد دوباره بفرستید. |
