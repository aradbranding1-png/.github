# بروزرسانی

## از داخل سامانه (روش اصلی)
مدیریت سامانه › بروزرسانی سامانه:
1. فایل ZIP نسخه جدید و رمز عبور خود را وارد کنید.
2. «نسخه پشتیبان کامل» (پیش‌فرض خاموش): اگر روشن باشد، دیتابیس هم پیش از بروزرسانی ذخیره می‌شود.
3. «یادداشت تازه‌های سامانه» (پیش‌فرض خاموش): انتشار خودکار از روی CHANGELOG بسته؛ «نامه رسمی» آن را برای همه کاربران هم می‌فرستد.

مراحل خودکار: نگه‌داری ← نسخه کوچک از کد فعلی (برای بازگشت خودکار) ← جایگزینی فایل‌ها ← Migration ← بررسی سلامت.
در صورت خطا، کد قبلی خودکار بازمی‌گردد. فایل `.env`، `storage`، `backups` و تصاویر کاربران هرگز دست نمی‌خورند.

## روش جایگزین (File Manager)
ZIP را در پوشه دامنه Extract کنید (Overwrite) و سپس:
`curl -X POST -H "X-Ops-Token: <OPS_TOKEN>" https://aradbranding.app/ops/migrate`

## قواعد Migration
- فقط رو به جلو و تکرارپذیر (IF NOT EXISTS، بررسی ستون و Index پیش از تغییر).
- هیچ Migrationای داده کاربر را حذف نمی‌کند.
