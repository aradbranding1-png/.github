# زبان‌های سامانه (۱.۱۹)

صفحه اصلی، ورود و عضویت و پنل کاربران به شش زبان نمایش داده می‌شوند: فارسی، انگلیسی، عربی، ترکی استانبولی، فرانسوی و روسی.

- فارسی زبان اصلی است. متن فارسی همان متن قبلی است و تغییر نکرده است.
- بخش مدیریت، API و نصب همیشه فارسی می‌مانند.

## انتخاب خودکار زبان

اولین مورد از این فهرست که صدق کند، زبان را تعیین می‌کند:

1. **پیوند با `?lang=xx`**، یا انتخاب خود کاربر.
   - انتخاب کاربر از منوی زبان (آیکون کره) در سربرگ همه صفحه‌ها انجام می‌شود.
   - این انتخاب یک سال در کوکی `lang` می‌ماند و روی حساب کاربر هم ذخیره می‌شود. پس از ورود در دستگاه دیگر، همان زبان برمی‌گردد.
2. **ربات موتورهای جستجو** نشانی ساده را فارسی می‌بینند. هر زبان با `?lang=xx` و پیوند `hreflang` معرفی شده است. به این ترتیب سئوی فارسی سایت دست نمی‌خورد.
3. **زبان اصلی مرورگر**، اگر یکی از زبان‌های سامانه غیر از انگلیسی باشد. مثلاً مرورگر فارسی همیشه فارسی می‌بیند، حتی با VPN.
4. **منطقه زمانی دستگاه**، از کوکی `tzl` که `assets/locale.js` می‌نویسد.
   - VPN نشانی IP را عوض می‌کند، ولی ساعت دستگاه را نه. پس ایرانیِ پشت VPN آلمان فارسی می‌بیند.
   - در اولین بازدید، اگر زبان فقط از روی IP حدس زده شده باشد و ساعت دستگاه زبان دیگری را نشان بدهد، صفحه یک بار دوباره بارگذاری می‌شود.
5. **کشورِ IP**:
   - اول از سربرگ CDN خوانده می‌شود: `CF-IPCountry`، `X-Country-Code` یا `CloudFront-Viewer-Country`.
   - اگر سربرگی نبود، از پایگاه آفلاین `app/Core/I18n/data` خوانده می‌شود.
6. **زبان‌های دیگر مرورگر**، و در نهایت **زبان پیش‌فرض** («زبان‌ها» ← زبان پیش‌فرض؛ مقدار اولیه انگلیسی).

### کشور ← زبان

| زبان | کشورها |
| --- | --- |
| فارسی | ایران و افغانستان |
| عربی | کشورهای عرب‌زبان |
| ترکی | ترکیه و جمهوری آذربایجان |
| روسی | روسیه، بلاروس، کشورهای آسیای میانه، ارمنستان و مولداوی |
| فرانسوی | فرانسه، بلژیک، لوکزامبورگ، موناکو و کشورهای فرانسوی‌زبان آفریقا |
| زبان پیش‌فرض | بقیه کشورها |

## «زبان‌ها» در بخش مدیریت

این بخش فقط برای مدیر کل است (دسترسی `i18n.manage`).

- **روشن یا خاموش کردن زبان‌ها**، زبان پیش‌فرض و تشخیص خودکار. با هر زبان درصد ترجمه‌شده هم نمایش داده می‌شود.
- **ویرایشگر ترجمه**: همه متن‌هایی که کاربران می‌بینند، با جستجو و فیلتر «بدون ترجمه» یا «ویرایش‌شده دستی».
  - متن فارسی هر عبارت از خود کد خوانده می‌شود. صفحه یا متنی که بعداً اضافه شود، خودکار در این فهرست می‌آید.
  - هر متنی که به زبانی بدون ترجمه نمایش داده شود، در جدول `translation_misses` ثبت می‌شود و در بالای فهرست قرار می‌گیرد.
  - ترجمه دستی روی ترجمه آماده (`app/Lang/{زبان}.php`) نوشته می‌شود و با دکمه «بازگشت به ترجمه آماده» حذف می‌شود.
  - نشانه‌های جایگزین متن اصلی مثل `:name`، `:n` و `{paid}` باید در ترجمه هم باشند. برای جمع و مفرد می‌توان از قالب ICU استفاده کرد: `{n, plural, one {# item} other {# items}}`.

## برای برنامه‌نویس

- هر متن رابط کاربری با متن فارسی‌اش از این تابع‌ها رد می‌شود:
  - `t('متن :name', ['name' => …])` متن ساده برمی‌گرداند.
  - `te(…)` نسخه escape‌شده برای HTML است.
  - `th(…)` برای متنی است که تگ ساده HTML دارد.
- در فارسی خود متن منبع بدون هیچ تغییری برمی‌گردد.
- اعداد و تاریخ:
  - `fa_num`، `fa_int`، `toman` و `fa_date` در فارسی همان خروجی قبلی را دارند.
  - در زبان‌های دیگر ارقام لاتین هستند و تاریخ میلادی است، به منطقه زمانی دستگاه کاربر.
- نام کشورها و زبان‌ها از داده‌های Unicode CLDR (ICU) می‌آید. نام دسته‌ها از ترجمه‌ها خوانده می‌شود.
- متن‌های جاوااسکریپت با `T('…')` ترجمه می‌شوند. دیکشنری‌شان در بلوک `#i18n-js` صفحه قرار می‌گیرد و فهرست منبع‌ها در `app/Lang/js.php` است.

## داده کشورِ IP

`app/Core/I18n/data/ipv4.bin` و `ipv6.bin` از پایگاه geo-whois-asn-country پروژه [ip-location-db](https://github.com/sapics/ip-location-db) ساخته شده‌اند. مجوز داده CC BY 4.0 و صاحب حق آن Number Resource Organization (https://www.nro.net) است.
