# API اتصال آراد کانتکت (نسخه ۱)

با این API، سامانه آراد کانتکت هنگام ثبت سفارش برای یک مشتری، کیف پول Stars او را در سامانه توسعه تجارت شارژ می‌کند:

- اگر مشتری با آن شماره موبایل حساب نداشته باشد، حساب برایش ساخته می‌شود و اطلاعات ورود (برای ارسال در تیکت) برمی‌گردد.
- بعداً هم می‌توان برای همان مشتری رمز ورود تازه صادر کرد.

## ۱. ساخت کلید

مسیر: پنل مدیریت ← **اتصال API** ← «کلید جدید».

- نام بگذارید و دسترسی‌ها را انتخاب کنید.
- در صورت نیاز، IP سرور آراد کانتکت را هم وارد کنید.
- کلید (`ab_xxxxxxxx_…`) **فقط یک بار** نمایش داده می‌شود. آن را در تنظیمات آراد کانتکت ذخیره کنید.
- اگر کلید لو رفت، از همان صفحه آن را باطل کنید و کلید تازه بسازید.

| دسترسی | کاربرد |
| --- | --- |
| `wallet.charge` | شارژ کیف پول؛ اگر حسابی نباشد، حساب هم ساخته می‌شود |
| `users.read` | استعلام حساب و موجودی با شماره موبایل |
| `users.credentials` | صدور رمز ورود تازه |

## ۲. قواعد مشترک

- نشانی پایه: `https://aradbranding.app/api/v1`
- احراز هویت با سربرگ `Authorization: Bearer ab_xxxxxxxx_…`. سربرگ `X-API-Key` هم پذیرفته می‌شود.
- بدنه درخواست‌ها JSON است، با سربرگ `Content-Type: application/json`.
- پاسخ همیشه این شکل را دارد: `{"ok": true|false, "data": {...}, "message": "..."}`
- شماره موبایل:
  - در `mobile` به هر یک از این شکل‌ها پذیرفته می‌شود: `09121234567`، `9121234567`، `+989121234567`، `00989121234567`. ارقام فارسی هم پذیرفته می‌شوند.
  - کد کشور در `country_code` فرستاده می‌شود و پیش‌فرض آن `98` است.
- سقف درخواست: ۳۰۰ درخواست در دقیقه. اگر بیشتر شود، پاسخ `429` با سربرگ `Retry-After` برمی‌گردد.

| کد | معنی |
| --- | --- |
| 200 | انجام شد |
| 401 | کلید نامعتبر، باطل‌شده، یا IP غیرمجاز |
| 403 | کلید این دسترسی را ندارد |
| 404 | حسابی با این شماره نیست (فقط در `users/credentials`) |
| 422 | داده نامعتبر؛ جزئیات در `data.errors` |

## ۳. شارژ کیف پول — `POST /wallet/charge`

```json
{
  "mobile": "09121234567",
  "country_code": "98",
  "stars": 1000,
  "order_id": "AC-2026-1045",
  "note": "بسته طلایی",
  "first_name": "علی",
  "last_name": "رضایی",
  "email": "ali@example.com",
  "create_account": true
}
```

| فیلد | الزامی | توضیح |
| --- | --- | --- |
| `mobile` | بله | شماره موبایل مشتری |
| `country_code` | خیر | پیش‌فرض `98` |
| `stars` | بله | عدد صحیح ۱ تا ۱٬۰۰۰٬۰۰۰ |
| `order_id` | بله | شناسه سفارش در آراد کانتکت (حداکثر ۸۰ نویسه). **یک سفارش هرگز دو بار شارژ نمی‌شود.** تکرار همان `order_id` همان پاسخ قبلی را با `"replayed": true` برمی‌گرداند و چیزی کسر یا اضافه نمی‌شود. |
| `note` | خیر | تا ۲۰۰ نویسه؛ در گردش حساب مشتری کنار «سفارش …» دیده می‌شود |
| `first_name`, `last_name`, `email` | خیر | فقط وقتی حساب تازه ساخته می‌شود به کار می‌روند. اگر ایمیل نباشد یا تکراری باشد، یک ایمیل داخلی ساخته می‌شود؛ مشتری با **شماره موبایل** وارد می‌شود. |
| `create_account` | خیر | پیش‌فرض `true`. اگر `false` باشد و حسابی نباشد، پاسخ `422` برمی‌گردد. |

پاسخ (حساب تازه):

```json
{
  "ok": true,
  "data": {
    "replayed": false,
    "account_created": true,
    "user": {"id": "01m3yx…", "name": "علی رضایی", "mobile": "+989121234567"},
    "transaction": {"id": 40, "stars": 1000, "balance": 1000, "order_id": "AC-2026-1045"},
    "credentials": {
      "login_url": "https://aradbranding.app/login",
      "username": "09121234567",
      "username_alt": "ali@example.com",
      "password": "zLzumGvib6nt",
      "ticket_text": "حساب کاربری شما در سامانه توسعه تجارت آماده است.\n…"
    }
  },
  "message": "Account created and wallet charged."
}
```

- `credentials` فقط وقتی حساب در همین درخواست ساخته شده باشد پر است. در بقیه موارد مقدار آن `null` است.
- رمز موقت در هیچ لاگی ذخیره نمی‌شود. آن را همان لحظه در تیکت مشتری بفرستید؛ متن آماده تیکت در `ticket_text` است.
- مشتری بعد از شارژ یک اعلان می‌گیرد. تراکنش با عنوان «شارژ کیف پول (ثبت سفارش در آراد کانتکت)» و توضیح «سفارش …» در گردش حسابش دیده می‌شود.

## ۴. استعلام — `GET /users/lookup?mobile=09121234567&country_code=98`

پاسخ:

```json
{"ok": true, "data": {"exists": true, "user": {"id": "…", "name": "…", "mobile": "+98…"}, "balance": 1750}}
```

اگر حسابی با این شماره نباشد: `{"exists": false}`.

## ۵. رمز ورود تازه — `POST /users/credentials`

درخواست:

```json
{"mobile": "09121234567"}
```

- یک رمز موقت تازه می‌سازد و نشست‌های قبلی مشتری را می‌بندد.
- `credentials` (با `ticket_text`) را مثل بالا برمی‌گرداند تا در تیکت ارسال شود.

## ۶. نمونه با curl

```bash
curl -X POST https://aradbranding.app/api/v1/wallet/charge \
  -H "Authorization: Bearer ab_xxxxxxxx_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"mobile":"09121234567","stars":1000,"order_id":"AC-2026-1045","note":"بسته طلایی"}'
```

## ۷. پیگیری

در صفحه «اتصال API» این موارد را می‌بینید:

- برای هر کلید: تعداد درخواست‌ها، مجموع Stars شارژشده و زمان آخرین استفاده.
- جدول آخرین درخواست‌ها با شماره سفارش، مشتری و نتیجه.

هر شارژ و هر صدور رمز در «رویدادهای امنیتی» هم ثبت می‌شود.
