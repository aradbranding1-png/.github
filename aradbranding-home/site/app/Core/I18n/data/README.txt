ipv4.bin / ipv6.bin — IP range → country, used only to pick a first language for new visitors.

Source: geo-whois-asn-country from ip-location-db (https://github.com/sapics/ip-location-db), build 2.3.2026061719.
Licence: Creative Commons Attribution 4.0 International (CC BY 4.0).
Copyright holder: Number Resource Organization (NRO) — data attribution: https://www.nro.net

Format: ipv4.bin = 6-byte records (uint32 big-endian range start + ISO 3166-1 alpha-2 code, "--" = unassigned);
ipv6.bin = 10-byte records (top 64 bits of the range start, big-endian + code). Records are sorted; adjacent ranges of the
same country are merged.
