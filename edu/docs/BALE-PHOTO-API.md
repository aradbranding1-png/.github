# درخواست از سامانه my: ارسال عکس همراه خبر

از نسخه ۱.۱.۳۹ سامانه آموزش در `POST /api/edu/bale/broadcast` یک فیلد اختیاری جدید می‌فرستد:

```json
{
  "ref": "event-40",
  "segment": "merchant",
  "text": "📢 میتینگ آنلاین جدید: …",
  "button": {"text": "مشاهده و ثبت‌نام", "url": "https://edu.aradbranding.me/learn/event/40"},
  "photo": "https://edu.aradbranding.me/cover/2f1c…-…/9a7e…c1.jpg"
}
```

- `photo`: لینک عمومی عکس کاور وبینار/میتینگ/دوره (JPEG، حداکثر عرض ۱۲۸۰، بدون نیاز به ورود). اگر جلسه یا دوره عکس نداشته باشد، این فیلد ارسال نمی‌شود.

## کاری که my باید انجام دهد
- اگر `photo` بود: به‌جای `sendMessage` از **`sendPhoto`** استفاده شود:
  `https://tapi.bale.ai/bot<TOKEN>/sendPhoto` با `chat_id`، `photo` = همان لینک، `caption` = `text` و `reply_markup` (همان دکمه).
- محدودیت طول caption (حدود ۱۰۲۴ کاراکتر): اگر `text` بلندتر بود، اول عکس بدون caption (یا با عنوان) و بلافاصله متن کامل با دکمه با `sendMessage` ارسال شود.
- برای فهرست‌های بزرگ بهتر است عکس یک بار آپلود شود و `file_id` برگشتی از اولین `sendPhoto` برای بقیه گیرندگان استفاده شود (سریع‌تر و بدون دانلود دوباره).
- اگر `sendPhoto` خطا داد (مثلاً دانلود عکس ممکن نبود)، همان پیام متنی قبلی (`sendMessage`) ارسال شود تا خبر از دست نرود.
- فیلد اختیاری است؛ تا وقتی my آن را پشتیبانی نکند، خبرها مثل قبل فقط متنی ارسال می‌شوند.
