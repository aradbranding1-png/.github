# بروزرسانی، Migration، پشتیبان‌گیری و بازیابی

## بروزرسانی از داخل پنل (فقط مدیر کل)
سیستم → **بروزرسانی سامانه** → آپلود ZIP. مراحل:
1. **اعتبارسنجی** (قبل از هر تغییر): سلامت ZIP، وجود و ساختار `manifest.json`، تطابق برنامه، نسخه جدیدتر از نسخه فعلی، `min_version`، نسخه PHP و افزونه‌ها، **Path Traversal / Symlink / مسیرهای مجاز** (فقط `app/`, `database/`, `public_html/` (بدون PHP به جز index.php), `docs/` و چند فایل ریشه — هرگز `.env` یا `storage/`)، **Checksum SHA-256** تک‌تک فایل‌ها، **بررسی نحوی PHP**، امضای دیجیتال Ed25519 (اختیاری/اجباری)، سطح دسترسی و فضای دیسک.
2. **نمایش برنامه:** فایل‌های جدید، تغییرکرده، حذف‌شونده، Migrationهای جدید، Health Check فعلی.
3. **اجرا** (با تأیید رمز مدیر کل) و سوییچ «تهیه Backup قبل از بروزرسانی»:
   Health Check → [پشتیبان: دیتابیس + تنظیمات + کد] → حالت تعمیر → نسخه برگشت از فایل‌های تغییرکننده → جایگزینی اتمیک هر فایل (temp + rename) → اجرای Migrationها → تست بوت HTTP (`/api/v1/health` در فرایند جدید) → خروج از حالت تعمیر.
4. **در صورت خطا:** فایل‌ها به نسخه قبل برمی‌گردند، فایل‌های جدید حذف می‌شوند، اگر Migration شکست بخورد و پشتیبان گرفته شده باشد دیتابیس خودکار بازیابی می‌شود، Migration ناقص و خطا در تاریخچه ثبت می‌شود و پشتیبان حفظ می‌شود.
5. **تاریخچه:** نسخه قبل/جدید، تاریخ و ساعت، مدیر، پشتیبان، Migrationها، وضعیت، خطا و گزارش کامل؛ امکان **بازگردانی دستی** (فایل‌ها و در صورت نیاز دیتابیس).

## ساخت بسته بروزرسانی (برای توسعه‌دهنده)
```
php cli.php package:update 1.1.0 --min=1.0.0 --changelog="تغییر ۱|تغییر ۲" [--key=/secure/private.key]
→ dist/aradedu-update-1.1.0.zip
```
ساختار: `manifest.json` + `files/<path>`. فایل‌هایی که در نسخه قبلی بوده‌اند و در نسخه جدید نیستند به صورت خودکار حذف می‌شوند (بر اساس manifest.json نصب‌شده).
### امضای دیجیتال (اختیاری، توصیه‌شده)
```
php cli.php keys:generate      # کلید خصوصی را خارج از سرور نگه دارید
```
کلید عمومی را در `.env` به صورت `UPDATE_PUBLIC_KEY=...` قرار دهید و در تنظیمات گزینه «فقط بسته‌های امضاشده» را فعال کنید.

## Migration
- فایل‌ها در `database/migrations/` با نام ترتیبی `YYYY_MM_DD_NNNNNN_name.php` که آرایه `['description'=>..., 'up'=>fn(PDO $db)]` برمی‌گرداند.
- صفحه **Migrationها**: اجرا شده / اجرا نشده (جدید) / ناموفق، ترتیب، Batch، تاریخ، زمان اجرا و Error. اجرای دستی فقط توسط مدیر کل (ثبت در Audit Log).
- CLI: `php cli.php migrate` و `php cli.php migrate:status`.

## پشتیبان‌گیری
- انواع: **دیتابیس** (همه اطلاعات آموزشی)، **پیش از بروزرسانی** (دیتابیس + .env + کد)، **کامل** (+ فایل‌های آپلودی و آواتارها).
- محل: `storage/backups/` خارج از Web Root؛ از URL قابل دسترسی نیست. دانلود و بازیابی فقط مدیر کل با تأیید مجدد رمز.
- Cron شبانه: پشتیبان دیتابیس و نگهداری ۱۰ نسخه آخر هر نوع.
- **بازیابی:** سیستم → پشتیبان‌گیری → بازیابی. پیش از بازیابی یک پشتیبان ایمنی خودکار گرفته می‌شود. تاریخچه پشتیبان‌ها و بروزرسانی‌ها حفظ می‌شود.
- CLI: `php cli.php backup full` و `php cli.php restore <id>`.
- بازیابی فایل‌ها از پشتیبان کامل: فایل ZIP را دانلود و پوشه `storage/uploads` را از آن جایگزین کنید.
