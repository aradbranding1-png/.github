# اتصال نظام رشد تاجر به سامانه خدمات/فروش

سامانه آموزش برای هر تاجر، **به ازای هر شماره موبایل ثبت‌شده او** یک درخواست به API سامانه فروش می‌فرستد و فهرست خدمات خریداری‌شده را می‌گیرد. نتیجه در جدول `tg_user_services` ذخیره می‌شود و نمایش نظام رشد فقط از همین جدول خوانده می‌شود.

## درخواست

به‌صورت پیش‌فرض:

```
GET https://sales.example.com/api/customer-services?mobile=09121234567&name=محمد%20احمدی
Authorization: Bearer <SERVICES_API_TOKEN>
Accept: application/json
```

- متد (GET یا POST با بدنه JSON)، نام پارامترها و قالب شماره (09… / 98… / +98… / 9…) در پنل قابل تنظیم است: «نظام رشد ← خدمات و سامانه فروش».
- اگر آدرس شامل `{mobile}` یا `{name}` باشد، مقدار همان‌جا جایگزین می‌شود؛ مثلاً `https://sales.example.com/api/customers/{mobile}/services`.
- کلید در فایل `.env` قرار می‌گیرد:

```
SERVICES_API_TOKEN=کلید-محرمانه
# اختیاری: اگر هدر دیگری لازم است (به‌جای Authorization: Bearer)
SERVICES_API_HEADER=X-API-Key
```

## پاسخ پیشنهادی

```json
{
  "ok": true,
  "data": [
    {"title": "طراحی برند", "code": "BRD-01", "status": "paid", "paid_at": "2026-05-10"},
    {"title": "سایت تجاری", "code": "WEB-02", "status": "paid", "paid_at": "2026-06-01 10:00:00"}
  ]
}
```

- مشتری بدون خرید: `{"ok": true, "data": []}` یا `{"ok": false, "message": "customer not found"}`.
- فهرست می‌تواند در `data`، `services`، `items`، `orders`، `data.services` یا ریشه پاسخ باشد، یا در پنل مسیر آن تعیین شود.
- نام فیلدها خودکار تشخیص داده می‌شود (title/name/service_name/product.title …، code/sku/id …، status/state/payment_status …، paid_at/date/created_at …) و در پنل هم قابل تعیین است.
- اگر «وضعیت‌های خریداری‌شده» در پنل پر شود (مثلاً `paid,active,done`)، فقط ردیف‌هایی با آن وضعیت‌ها خرید حساب می‌شوند.
- تاریخ میلادی، شمسی (۱۴۰۵/۰۲/۲۰) یا Unix timestamp پذیرفته می‌شود.

## نگاشت خدمات

هر نام/کد دریافتی با «فهرست خدمات نظام رشد» مقایسه می‌شود. برای هر خدمت می‌توان چند نام یا کد سامانه فروش را ثبت کرد. نام‌هایی که به هیچ خدمتی وصل نشده‌اند در بخش «نام‌های بدون نگاشت» نمایش داده می‌شوند تا با یک کلیک متصل شوند.

## زمان بروزرسانی

- «بروزرسانی خدمات تمام مشتریان» در پنل (به‌صورت دسته‌ای؛ اگر صفحه بسته شود، Cron ادامه می‌دهد).
- «بروزرسانی خدمات» در صفحه نظام رشد هر تاجر.
- خود تاجر هم در صفحه «نظام رشد تاجر من» می‌تواند حداکثر ۳ بار در ساعت خدماتش را بروزرسانی کند.
